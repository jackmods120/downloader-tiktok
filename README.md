## 🚀 ڕێنمایی دامەزراندن

### پێشمەرجەکان

```bash
Python 3.11+
Vercel Account
Firebase Realtime Database
Telegram Bot Token
```

### ١. کۆپیکردنی پڕۆژەکە

```bash
git clone https://github.com/j4ck721s/jacktik-bot.git
cd jacktik-bot
pip install -r requirements.txt
```

### ٢. دانانی گۆڕاوەکانی ژینگە

```env
BOT_TOKEN=your_telegram_bot_token_here
DB_URL=https://your-project.firebaseio.com
DB_SECRET=your_firebase_secret_key
```

### ٣. دانانی Vercel Webhook

لەدوای دیپلۆی کردن لە Vercel:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://your-project.vercel.app/api/main
```
